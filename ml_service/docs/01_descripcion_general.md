SizeSoft ERP - Módulo de Mantenimiento
¿Qué es SizeSoft ERP?
SizeSoft ERP es un sistema de gestión empresarial diseñado para ayudar a los trabajadores de una empresa a gestionar el mantenimiento de sus máquinas, equipos y piezas. El objetivo principal es agilizar el proceso de mantenimiento: cuando una máquina o equipo se daña, el sistema permite verificar rápidamente si las piezas de repuesto están disponibles en inventario o si es necesario pedirlas.

¿Cómo acceder al sistema?
El sistema requiere codigo de compañia, usuario y contraseña para ingresar. Una vez dentro, el menú superior muestra las opciones de Maestros y Transacciones. En la parte superior derecha se muestra el nombre del usuario conectado.
## ¿Cómo iniciar sesión?
1. Abre el navegador y ve a la dirección del sistema
2. Ingresa tu **usuario** y **contraseña** en el formulario de login
3. Haz clic en **Iniciar Sesión**
4. Si las credenciales son correctas, serás redirigido al módulo principal
5. En la esquina superior derecha verás tu nombre de usuario confirmando que ingresaste correctamente

## ¿Qué hago si olvidé mi contraseña?
Contacta al administrador del sistema para que restablezca tu contraseña.
