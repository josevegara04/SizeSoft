Listado de Repuestos
¿Qué es?
El Listado de Repuestos es el inventario de piezas de reemplazo disponibles en la empresa. Permite saber qué repuestos hay en stock para realizar mantenimientos sin necesidad de hacer pedidos externos.
¿Para qué sirve?
Cuando una máquina se daña, el técnico o trabajador puede consultar este módulo para verificar si la pieza que necesita está disponible en inventario. Si está disponible, el mantenimiento puede realizarse de inmediato. Si no está disponible, se debe gestionar un pedido.
¿Cómo registrar un repuesto?

Ir al menú Maestros → Repuestos
Completar los datos del repuesto
Hacer clic en Guardar

¿Cómo buscar un repuesto?

Ingresar el código o nombre del repuesto
Hacer clic en el botón de búsqueda (lupa)
El sistema mostrará la información del repuesto incluyendo disponibilidad

Relación con otros módulos

Los repuestos están relacionados con las Partes del listado de partes
Se usan en las Órdenes de Servicio cuando se realiza un mantenimiento
Cuando se daña una máquina, se consulta este módulo para verificar disponibilidad antes de generar una orden de servicio
